# Compliance Conventions

Non-negotiable rules for all campaign-facing agent output.

## Rules

1. **No legal advice** — Flag compliance concerns; recommend a qualified election-law attorney for binding decisions.
2. **Disclaimers** — Paid-for-by and authority lines must match the campaign's jurisdiction requirements when drafting paid media.
3. **Recordkeeping** — Note when content should be logged for FEC/state disclosure (stubs until compliance module is wired).
4. **Fabrication** — Never invent poll numbers, endorsement lists, or donor amounts.
5. **Opposition research** — Label unverified claims; distinguish public record from inference.

## When to invoke

- Any skill that produces copy for voters, donors, or public channels.
- Before scheduling automations that send outbound messages.
